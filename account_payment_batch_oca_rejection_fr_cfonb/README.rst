This module adds a wizard to import rejection CFONB files.

For the moment, it supports CFONB rejection files for SEPA direct debit
and LCR.

**Table of contents**

.. contents::
   :local:

Usage
=====

Go to *Accounting > Accounting > Actions > Import Rejection Files* and
upload one or several CFONB rejection files.
